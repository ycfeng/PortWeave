# PortWeave 0.1.0 发布说明

状态：首个公开候选版本，本文档本身不代表版本已发布。

## 主要能力

- 支持 SSH 密码/私钥认证、本地端口转发、严格主机指纹校验。
- 支持纯 Kotlin frpc STCP visitor，不需要 GoMobile、NDK 或原生库。
- 支持无环依赖链、共享父节点租约、单飞启动、失败回滚和网络恢复。
- 支持前台服务、持续通知、结构化脱敏日志、诊断包和无秘密配置导入导出。
- 支持系统/浅色/深色主题、TalkBack 状态与操作语义以及手机/平板自适应布局。

## 兼容性

- 最低 Android 8.0（API 26），目标 Android API 36。
- 本地监听固定为 IPv4 回环地址 `127.0.0.1`；首版仅支持 TCP。
- STCP 实现以 frp v0.69.1 协议兼容测试为当前基线。

## 升级与迁移

这是首个公开候选版本，没有需要支持的公开旧版本升级路径。数据库包含显式 schema 迁移测试；默认导出不包含凭据，迁移设备前需要在新设备重新补充秘密。

## 安全与隐私

秘密由 Android Keystore 支持的加密存储保存，不进入 Room、配置导出、正式日志或诊断包。SSH 未知主机需要确认，已保存指纹变化会阻断连接。详情见 `PRIVACY.md`。

## 已知限制

- 本轮按验证范围仅在 API 36 / x86_64 / 16 KB page-size 模拟器完成插桩与冷启动；其他 API 版本、真机、Doze 和厂商省电策略未在本轮执行，不能由主机测试推断为通过。
- 发布 APK 在未提供发布密钥时为 unsigned；签名、商店审核与下载后安装验证属于发布人员门禁。
- STCP 未配置 TLS 证书 SHA-256 固定值时使用 frp 兼容的未认证 TLS；需要服务器身份保证的部署必须配置并核对固定值。
- 不支持 UDP、VPN 全局代理、`0.0.0.0` 监听、设备重启后静默恢复或配置云同步。
