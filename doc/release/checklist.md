# 阶段 F 发布检查清单

每个候选版本都应保留实际命令、制品哈希和设备记录。未执行项目不得根据代码推断为通过。

## 自动门禁

- [x] `./gradlew releaseQualityCheck` 通过。
- [x] `tools/verify-reproducible-build.ps1` 的两次 unsigned release APK SHA-256 一致。
- [x] release APK 中存在 `assets/licenses.txt`，并包含项目许可证、NOTICE、第三方清单和许可证文本。
- [x] release APK 不包含 GoMobile、`libgojni.so` 或应用自有 NDK 制品，不包含测试依赖或明文秘密。
- [x] Lint 没有 error，关键单元/集成/迁移/1000 次启停压力测试通过。
- [x] SSH 100 个并发本地客户端、STCP 100 个并发 relay 与 100 个真实本地 Socket 接入测试通过；第 101 个 STCP relay 按容量保护被拒绝。

## 无障碍与尺寸

- [ ] TalkBack 可朗读配置名称、后端类型、状态，以及打开详情、启动/停止操作。
- [x] API 36 自动语义测试已校验首页配置卡包含配置名、后端类型、状态描述，以及“查看详情”“启动映射”自定义操作；人工听读仍按上一项执行。
- [ ] 触摸目标至少 48 dp，状态不只依赖颜色表达。
- [x] API 36 原生手机竖屏以及 2560×1600 / 240 dpi（宽度大于 840 dp）横屏下，端到端主页面导航测试通过。
- [x] API 36 系统字体 200% 时，首页、详情、日志、设置和编辑器端到端导航通过，编辑器可滚动到保存操作。
- [x] API 36 正式候选在浅色、深色和默认动态取色下完成首页目视检查，截图已归档；含配置与错误状态的完整人工走查仍需随真实数据面测试执行。

## 设备、网络与稳定性

- [x] 按本轮限定范围，仅 API 36 / x86_64 / 16 KB page-size 模拟器 smoke test、冷启动和插桩测试通过；未安装或验证其他 API 版本。
- [ ] 通知允许/拒绝、后台、进程重建、Wi-Fi/蜂窝切换、飞行模式、熄屏和 Doze 已检查。
- [ ] SSH 密码、SSH 私钥和 STCP 真实服务端数据面检查通过，包括停止后端口释放。
- [ ] 8 小时持续运行和周期断网恢复完成，记录 CPU、PSS、耗电、FD、线程和残留 Socket。
- [x] 主机侧 100 个并发本地客户端压力通过；API 36 空闲冷启动基线已记录 PSS、FD 和线程数。
- [ ] 运行前后无残留通知、Job、监听 Socket 或无租约会话。

## 法律、隐私与发布

- [x] `VERSION_NAME`/`VERSION_CODE`、`release-notes/v0.1.0.md` 与候选版本一致。
- [x] `PRIVACY.md` 与实际权限、存储、网络、日志、导出和备份行为一致。
- [x] `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md` 及第三方完整许可证已审查。
- [x] 发布签名门禁和 `assembleRelease` 通过，三 ABI APK 的签名与 SHA-256 已验证；x86_64 在 API 36 上全新安装、冷启动和同签名覆盖安装通过。
- [ ] 发布负责人确认发布证书身份、离线备份/恢复流程，并完成商店上传审核。
- [x] 公布已知限制，不把主机测试或模拟器结果描述为真机/长时间稳定性证据。
